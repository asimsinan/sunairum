# Academic Blueprint — Method

## Communication Method

- Preferred mode: instructional
- Argument flow: motivation → prior work → mechanism → equations → experiments → ablation → conclusion
- One contribution / mechanism / result per page
- Pair formulas with intuition; keep figure and claim on the same page

## Page Role Vocabulary

| Role | Composition tendency |
|---|---|
| Cover | Full-bleed atmosphere with calm title region |
| Why it matters | KPI / hero metrics with one-line takeaway |
| Evolution and context | Timeline or side-by-side progression |
| Limitations of prior work | Parallel columns / pillars |
| Architecture overview | Diagram-dominant with hotspot sidebar |
| Mechanism detail | Diagram or cross-section with adjacent text |
| Formula block | Formula band with surrounding context |
| Comparison table | Native table with takeaway band |
| Training and setup | Parameter grid / KPI cards |
| Results | Table or chart with bottom takeaway |
| Ablation | Numbered key-point list |
| Conclusion | Centered closing with restrained backdrop |

## Visual defaults (soft — pack lock wins)

- Obey the **resolved pack or confirm_ui lock** for palette, type, and icons.
- Prefer ink-dominant fields over pale secondary_bg wallpaper when the lock is blueprint/academic.
- Vertical accent bar beside titles is an **optional motif**, not mandatory every page.
- Formulas: mixed — block equations as PNG in labeled formula-band; inline Unicode/Consolas.
- Icons: from lock (often tabler-outline stroke 2).
- Vary composition across pages; do not stamp identical card stacks.
