# Pipeline method DNA (general free_design)

Use on every free_design run. Optional user presentation style may append more method lines; it does not replace these defaults.

## Fill Contract (color usage)

- Content pages: energy=`vivid`. Title / hero / closing stay `sparse`.
- Prefer `accent_tint` (or primary/accent at low opacity) for surfaces and claim panels — not pale neutral wallpaper alone.
- Paint solid primary/accent mass at least once per content page (bar, filled panel, or host accent). Hairline-only chrome is not enough.
- Injected claim/formula/table surfaces use palette tokens (`accent_tint`, `secondary_accent`, `primary`) — never invent a second palette.

## Style method (science / technical / consulting)

- One idea per page; visual and idea co-located (figure/table/formula beside claims, not footer-only).
- Diagram or evidence dominates when present; explanation stays adjacent (not only below the fold).
- Keep a stable spatial convention across recurring diagrams (flow direction, layer order, focus accent).
- Message and proof on the same page; one clear scan path; do not detach the recommendation into a competing decorative box.
- Color has a fixed explanatory job across the deck; saturated accent = component or claim under discussion.

## References DNA (executor / strategist grammar)

- Hierarchy via type, leading, alignment, and space before decoration.
- Boundary ladder: spacing → rule → tint → outline → panel → float. Containers only when they encode grouping or hierarchy.
- Meaning-bearing text must contrast on its actual background; color alone never carries a required distinction.
- `page_rhythm=breathing`: no multi-card grids; cards only for real peer groups.
- `consumption_mode=presentation`: one claim + one dominant visual; `balanced`: claim + evidence on-slide.
- Paraphrase only if information-equivalent; never invent or drop claims or move content across pages — return upstream.
- Cover = hook + anchor; closing = real takeaway (not empty Thanks); neighbor rhythm intentional.
- Structure: relationship before styling; garnish removable without losing meaning.
- Chart: domain → frame → marks → labels → style; values own marks; bars from zero.
- Table: grid before decoration; physical grid ≠ table; do not drop rows/cols to fit.
- Mode ≠ visual style: `pyramid` / `narrative` / `instructional` / `showcase` / `briefing` shape argument and title voice only.
